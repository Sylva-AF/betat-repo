## Betat Community Framework v0.1.0

*The human record, for the other person.*

---

### What Betat is

A child born today will grow up in a world where it is increasingly
impossible to tell whether something was created by a human being —
or generated by a machine. Betat is an open framework that lets
communities of real people create permanent, verified records of
human-originated content. Every verified record carries the **HI**
tag — Human Intelligence — and is publicly readable, free, forever.

Betat is a protocol, not a platform. Communities install it on
infrastructure they control. Their records belong to them. No
central authority holds the data. No account on betat.org is
required to read a record.

---

### What this release delivers

This is the first public release of the reference community
framework — everything a community needs to go from zero to
a working provenance registry.

**For community operators:**
- `pip install betat-community` installs the complete framework
  in one command, including Django, the REST API, and all
  authentication plugins
- `betat init` walks through community setup interactively —
  community identity, content type, authentication methods,
  operator declaration — and writes a production-ready
  configuration
- A browser-based setup wizard is available as an alternative
  to the CLI for less technical operators
- SQLite works out of the box with zero configuration;
  PostgreSQL is supported by setting one environment variable

**For community members (Provenanciers):**
- Enroll through peer vouching, cryptographic key (passphrase-
  based — no raw hex keys required), or institutional identity
- Submit content by providing a permanent link and a content
  fingerprint — Betat records provenance, never the content itself
- Every submission is reviewed by a community verifier before
  it becomes a permanent record

**For the public:**
- Every accepted record is publicly readable through the
  community's Records page and the federation API
- Records are append-only and permanent — once issued, a
  provenance record cannot be silently changed or deleted
- The content hash in every record lets anyone verify that
  the content at the link is still what was originally submitted

**What is built under the hood:**
- Append-only provenance store with SHA-256 integrity verification
- Pluggable authentication floor (peer vouch, crypto key,
  institutional — communities choose their methods at setup)
- Passphrase-derived Ed25519 keypairs for cryptographic enrollment
  — the user sets a passphrase, the key is generated invisibly
- Four public federation API endpoints for crawlers and indexes
- Bundled UI: Records, Contribute (enrollment + submission),
  Review queue, Timeline placeholder (v0.2)
- Phase 1 installer screen with the Betat eclipse animation
- `betat` CLI: init, start, backup, announce, export
- Founding-phase enrollment: the first two community members
  are approved by the administrator directly — peer vouching
  activates once two members are enrolled

### How to get started

**Install:**
```bash
pip install betat-community
```

**Set up your community:**
```bash
betat init
python manage.py migrate
python manage.py createsuperuser
betat start
```

Visit `http://localhost:8000/community/` — your community is running.

**Full documentation:** https://betat.org/for-builders.html

**Questions and contributions:** https://github.com/Sylva-AF/betat-repo/discussions

### What comes in v0.2

v0.2 is already designed and documented in `ROADMAP.md`.
The two major additions:

**Timeline tree and backfill mechanism** — a public-facing
visualization of existing human-originated content on the
internet, indexed by year of creation. Enrolled Provenanciers
assert or flag content. Confirmed content becomes a permanent
Betat record. The timeline is visible to everyone; asserting
requires enrollment. This is how Betat addresses the ocean of
content created before communities began recording provenance
at creation time.

**Cross-community network features** — Provenanciers enrolled
in one community can request recognition in another, carrying
their verified identity across communities. Communities can
declare trust relationships with each other. The registry
network graph shows which communities spawn new communities
as the network grows organically.

v0.2 begins after the first real communities are running on
v0.1 and producing real records. The timeline tree needs
content to point to before the visualization means anything.

### The name

*Betat* — from the Bamileke language of the Bantu people,
Cameroon. It means "the other person" — humanhood.

The framework is built around that idea: the record exists
for the other person. The researcher who will need to know
this knowledge came from a human. The community that will
need to prove their cultural knowledge is theirs. The future
that will need to distinguish what was made by people from
what was generated by machines.
