# For Builders

The technical documents — for Contributors who want to build. **Architecture** defines the protocols and the registry model; the **Community Framework** specifies the install-and-run reference implementation; the **Provenance Spec** defines the record format everything conforms to; **Rendering the Record** previews how one record becomes both the machine payload and the human-facing result.
